Full Godot Game

Clone the repo and open in Godot 4.6 — the 2.5D world (world_25d.tscn) is the default scene.
Desktop play: clone → open D:\RPG_Quest_2D in Godot 4.6 → press Play (or run Play_Game.bat).
Move WASD/arrows · attack Space/J · switch hero Tab.
